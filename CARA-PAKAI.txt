CARA MENAMBAHKAN FOTO & MEMPUBLIKASIKAN TUR 360°
==================================================

STRUKTUR FOLDER INI:
  tour/
   ├─ index.html        <- file utama, jangan diganti nama
   ├─ images/            <- taruh semua foto 360° (equirectangular) di sini
   └─ CARA-PAKAI.txt      <- file ini


LANGKAH 1 — Masukkan foto / video
------------------------------------
Salin foto panorama (equirectangular, rasio 2:1) ATAU video panorama
hasil render Blender + edit Premiere (juga rasio 2:1, format mp4/webm,
sudah di-loop) ke dalam folder images/. Contoh:

  images/lobby.jpg
  images/taman-belakang.mp4
  images/kamar-utama.jpg

Nama file bebas, tapi hindari spasi — pakai tanda hubung (-) atau garis
bawah (_) sebagai gantinya. Video otomatis dikenali dari ekstensi file
(.mp4, .webm, .mov, .ogv) — tidak perlu pengaturan tambahan.

Catatan video: video akan diputar otomatis dalam kondisi tanpa suara
(muted) dan berulang (loop) begitu spot itu dibuka. Ini standar browser
modern untuk video autoplay. Jika browser pengunjung tetap memblokir
autoplay, akan muncul tombol "▶ Putar Video" di tengah layar sebagai
cadangan.


LANGKAH 2 — Daftarkan foto di index.html
------------------------------------------
Buka index.html dengan text editor (Notepad, VS Code, dll). Cari bagian
bertuliskan "SCENE_MANIFEST" di dekat awal kode (Ctrl+F), lalu isi
seperti ini:

  var SCENE_MANIFEST = [
    {
      name: "Lobby", src: "images/lobby-marmer-putih.jpg",
      materialZones: [
        { id: "lantai", label: "Lantai", lat: -35, lon: 10,
          options: [
            { key: "marmer", label: "Marmer" },
            { key: "kayu", label: "Kayu" },
            { key: "granit", label: "Granit" }
          ] },
        { id: "dinding", label: "Dinding", lat: 5, lon: 60,
          options: [
            { key: "putih", label: "Putih" },
            { key: "abu", label: "Abu-abu" }
          ] }
      ],
      combos: {
        "marmer|abu": "images/lobby-marmer-abu.jpg",
        "kayu|putih": "images/lobby-kayu-putih.jpg",
        "kayu|abu": "images/lobby-kayu-abu.jpg",
        "granit|putih": "images/lobby-granit-putih.jpg",
        "granit|abu": "images/lobby-granit-abu.jpg"
      },
      hotspots: [
        { lat: -8, lon: 120, target: "Taman Belakang" }
      ]
    },
    { name: "Taman Belakang", src: "images/taman-belakang.jpg", hotspots: [] },
    { name: "Kamar Utama", src: "images/kamar-utama.jpg", hotspots: [] },
  ];

Setiap baris = satu spot yang otomatis muncul di panel kiri untuk semua
pengunjung. Urutan baris = urutan tampil di daftar. Simpan file setelah
selesai.

ZONA MATERIAL (klik di titik pada gambar untuk ganti lantai/dinding/
dll secara independen): karena viewer bekerja dengan menukar SELURUH
foto (bukan mengganti material secara real-time), setiap KOMBINASI
pilihan butuh foto render-nya sendiri. Contoh di atas: 1 zona "Lantai"
(3 pilihan) x 1 zona "Dinding" (2 pilihan) = 6 kombinasi foto total.
Foto default (src di atas) otomatis jadi kombinasi "marmer|putih" —
sisanya (5 kombinasi lain) didaftarkan di "combos", dengan key berupa
gabungan option key tiap zona (urutan sesuai urutan zona di
materialZones), dipisah tanda "|".

Render tiap kombinasi di Blender dengan SUDUT KAMERA PERSIS SAMA,
hanya materialnya yang beda sesuai kombinasinya. Simpan sebagai file
terpisah di images/, lalu daftarkan di "combos" seperti contoh di
atas.

Cara termudah menyiapkan semua ini tanpa mengetik manual: buka
index.html di browser, klik tombol "Zona Material" lalu klik di titik
pada gambar (misal di lantai) untuk membuat zona baru dan isi nama
pilihannya (misal: Marmer, Kayu, Granit) — ulangi untuk zona lain
(misal Dinding). Setelah semua zona dibuat, klik "Kelola Kombinasi" —
akan muncul daftar semua kombinasi yang mungkin, tinggal upload foto
satu per satu di baris yang sesuai. Setelah semua terisi, klik
"Ekspor Konfigurasi" — teks SCENE_MANIFEST lengkap (termasuk
materialZones, combos, & hotspots) otomatis dibuatkan, tinggal
disalin ke index.html Anda.

Catatan: tombol "+ Tambah Spot", "Edit Hotspot", "Zona Material", dan
"Kelola Kombinasi" di viewer sangat berguna untuk mencoba dan mengatur
tata letak, tapi perubahannya HANYA berlaku untuk sesi Anda saat itu
(hilang saat halaman ditutup). Untuk permanen dilihat semua
halaman ditutup). Untuk permanen dilihat semua pengunjung, WAJIB
disalin lewat "Ekspor Konfigurasi" ke SCENE_MANIFEST di atas.



LANGKAH 3 — Publikasikan (contoh: Netlify, termudah)
-------------------------------------------------------
0. SEBELUM upload: buka index.html, cari "MODE_EDITOR" di dekat baris
   paling atas kode, ubah dari "true" jadi "false", lalu simpan. Ini
   menyembunyikan semua tombol edit (+ Tambah Spot, Edit Hotspot, Zona
   Material, Kelola Kombinasi, Ekspor Konfigurasi) dari pengunjung
   publik — mereka hanya bisa MELIHAT tur yang sudah Anda siapkan,
   tidak bisa menambah/mengubah apa pun. Simpan dulu SATU salinan
   dengan MODE_EDITOR = true untuk Anda sendiri pakai menyiapkan
   konten nanti.
1. Buka https://app.netlify.com/drop di browser
2. Seret (drag & drop) seluruh folder "tour" ini ke halaman tersebut
3. Tunggu beberapa detik — Netlify akan memberi Anda link publik,
   contoh: https://nama-acak-123.netlify.app
4. Selesai. Link itu bisa dibagikan ke siapa saja.

Alternatif lain: GitHub Pages atau Cloudflare Pages — caranya serupa,
upload folder ini apa adanya (jangan diubah strukturnya).

PENTING: jangan membuka index.html dengan cara dobel-klik di komputer
(file://) untuk versi final — foto tidak akan tampil karena browser
memblokir akses gambar lokal ke WebGL demi keamanan. Foto HANYA akan
tampil otomatis setelah folder ini benar-benar di-hosting (http/https).


LANGKAH 4 — Update foto di kemudian hari
-------------------------------------------
Ganti/tambah file di folder images/, edit SCENE_MANIFEST sesuai
kebutuhan, lalu upload ulang folder "tour" ke platform hosting yang
sama (drag & drop lagi di Netlify, atau git push jika pakai GitHub
Pages).
